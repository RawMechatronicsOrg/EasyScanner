# Easy Scanner assembly

The whole scanner as built: phone (a Galaxy S24 dummy), phone clamp, the 16 × 13 × 1.5 mm aluminium
U profile, and the ball-head laser mount with a schematic 12 mm line laser.

| File | What it is |
|---|---|
| `easy_scanner.step` | The assembly, one product per part, with colours |
| `EasyScanner.FCStd` | The same in FreeCAD 1.0 (App::Part tree, no constraints) |
| `easy_scanner.glb` | The same as glTF for viewers and renderers |
| `render_blender.py` | The renders in [`docs/images`](../../docs/images): `blender -b --factory-startup -P render_blender.py` |

## Frame and parts

Millimetres, Z up along the screen normal (the camera and the laser look down −Z), X along the profile
toward the laser, origin under the phone's centre, the lowest point at z = 0.

| Part | Source |
|---|---|
| Phone Clamp Lower, Upper, Screw Top/Bottom, Knurled Head | [`../phone-clamp`](../phone-clamp/README.md) (the base drawn as clean solids, same fits) |
| Profile 16x13 U | aluminium U channel, 120 mm, open side toward the phone |
| Laser Mount Clip | [`../models/flange_clip.py`](../models/flange_clip.py): grips one flange of the U profile |
| Laser Mount Ball, Nut | [`../models/ball_mount.py`](../models/ball_mount.py) |
| Laser Clamp | [`../models/laser_clamp_cross.py`](../models/laser_clamp_cross.py) |
| Line Laser 12x30 (schematic), Galaxy S24 (dummy) | stand-ins for the bought parts, approximate |

The assembly is exported from the design model of the scanner, so it is not regenerated by a script
in this repository; the printable parts are (`../export_stl.py`).
